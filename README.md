No setup, no explanation after it — the line lands on its own.

2-0 (margin +6) in front of the real jury model, then beat fellow challenger
I 3-1 in a 4-call playoff. See `candidates-v2.md` and `scores-v2.md` for the
full tournament.

The program (`main.ts`, Node 22) writes the line to `/output/entry.txt`:
one UTF-8 text, 1–200 characters, no trailing newline.
